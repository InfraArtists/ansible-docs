# Running comman with sudo permission 

`-b` or `--become` used to be sudo user or more permission

`-k` or `--ask-become-pass` used for asking sudo password

let's do some example.

### `apt`/`yum` module — install a package

```bash
ansible -u milad -m apt -a "name=htop state=present" -b youtube-servers
```
`-b` (become) runs the task with sudo, needed for anything requiring root, like installing packages.

### `copy` module — copy a file to hosts

```bash
ansible -u milad -m copy -a "src=./motd dest=/etc/motd" -b youtube-servers
```

### `service` module — manage a service

```bash
ansible -u milad -m service -a "name=nginx state=restarted" -b youtube-servers
```

# Limiting the target hosts

Use `--limit` (or `-l`) to run against a subset of a group:

```bash
ansible -m shell -a "df -h" all -l 192.168.122.40
```

**If you want to exclude some host you can use ! for the hostname or IP**

```bash
ansible -u milad -m apt -a "name=htop state=present" -b youtube-servers -l "!192.168.122.11"
```
